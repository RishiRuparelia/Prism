## Movies and TV

The full feature includes the [Movies/TV page](public/prism/movies.html), [interface code](public/prism/movies.js), [player behavior](public/prism/movie-playback.js), [series state](public/prism/series-state.js), [catalog API](app/api/movies/route.ts), [catalog data](public/data/), and [local artwork](public/media/). Catalog entries can reference external providers; the actual external movie videos and third-party game distributions are not local source files.

## Build-generated files

`npm ci` installs the dependencies recorded in `package-lock.json`. `npm run build` generates `dist/server`, `dist/client`, and `public/rooster-source.zip`. Those generated outputs, installed dependencies, local database state, and private environment files are excluded from the committed source. The package scripts recreate the deployment output from these files.
