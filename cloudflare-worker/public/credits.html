A little help from good projects.

Prism combines its original Egyptian scene and gold interface with the following open projects and external catalogs. Games and videos retain their respective creators’ rights and are delivered by their original hosts.

Source code

Rooster is distributed under AGPL-3.0. Download the corresponding Rooster source · License. The archive includes application source, dependency lockfile, schema, and build scripts. Install dependencies with npm ci; run npm run dev for a local preview.

Prism frontend

Adapted directly from RishiRuparelia/Prism. Copyright (c) 2026 RishiRuparelia, MIT license. Original license. The animated scene and original game/settings design are retained, with proxy fixes and new matching movie/chat pages.

Games

The 500-game catalog is adapted from 55gms/55GMS, pinned to commit 183754e50598d4dab26b9107404d983ca562833b, licensed under AGPL-3.0. Original game code and assets remain on 55gms/assets and the upstream game hosts. Original catalog · Provenance. A full upstream application source ZIP is saved in the local project’s outputs/source directory.

Proxy

The browser uses Ultraviolet 2.0.0 (AGPL-3.0), with an original Cloudflare Worker implementation of the Bare v3 protocol. Upstream source: Ultraviolet v2 and exact dependency release.

Movies

Metadata and artwork come from Cinemeta by Stremio. Video playback is supplied by the external provider selected in Settings; the default uses the same movie URL pattern found in 55gms. Rooster does not store video files. Direct-play classics are supplied by the Internet Archive; individual sources and license records are included.

Interface

Icons by Lucide (ISC). Typography: Cinzel and Rajdhani via Google Fonts (SIL Open Font License). Built with React, Vinext, and Cloudflare Workers/D1.
